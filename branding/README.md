# Identité visuelle — proposition

| Fichier | Usage |
|---|---|
| `logo-mark.svg` | Symbole seul : icône d'application, favicon, réseaux sociaux |
| `logo-horizontal.svg` | Symbole + nom : site web, en-têtes, documents |
| `logo-monochrome.svg` | Une couleur (`currentColor`) : tampon, gravure, fond photo |

**Idée** : une facture au coin plié et la pastille orange « payé » cochée. Le produit sert à faire ses factures
*et* à se faire payer. Pas de croix suisse : son usage commercial est encadré par la loi sur la protection des
armoiries (LPAP).

**Couleurs**

| Nom | Valeur | Rôle |
|---|---|---|
| Encre | `#1F3D6B` | Couleur principale (fond du symbole, texte du logo) |
| Papier | `#FFFFFF` | Document |
| Brume | `#B9CBE6` | Coin plié, lignes secondaires |
| Payé | `#F29A2E` | Accent : pastille, « & », appels à l'action |

**Typographie** : Bricolage Grotesque (titres, logo) et Open Sans (texte, déjà utilisée dans les PDF de l'application),
toutes deux sous licence SIL Open Font License, hébergées avec le site.

**Avant un usage imprimé** : faire vectoriser le texte de `logo-horizontal.svg` (il dépend de la police installée).
Un nom de marque distinctif serait plus facile à protéger que « Devis & Factures », purement descriptif.
